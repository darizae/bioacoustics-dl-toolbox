# bioacoustics-dl-toolbox — Spectral Grid bundle

This is the simplified brand bundle for **bioacoustics-dl-toolbox**, based on the **Spectral Grid** direction.

## What is included

A deliberately small set of essentials:

1. `source/mark.svg` — bare spectral mark for diagrams or badges.
2. `source/mark-tile.svg` — square app/icon tile.
3. `source/lockup.svg` — primary lockup for light backgrounds.
4. `source/lockup-inverse.svg` — lockup for dark backgrounds.
5. `png/mark.png` — raster export of the mark.
6. `png/lockup.png` — raster export for light backgrounds.
7. `png/lockup-inverse.png` — raster export for dark backgrounds.
8. `icons/icon-32.png`
9. `icons/icon-128.png`
10. `icons/icon-256.png`
11. `icons/favicon.ico`
12. `previews/lockups-light-and-dark.png`

Total: **12 files** plus this README.

## Palette

- Ink: `#102235`
- Night: `#0C1624`
- Accent: `#1DA1FF`
- Deep Accent: `#0A6FD1`
- Pale: `#DCEEFF`
- Paper: `#F7FAFE`

Compared with the earlier exploration, this version keeps the same blue/navy family but increases contrast for better readability and crisper small-size icons.

## Recommended use

- Use `png/lockup.png` or `source/lockup.svg` on light backgrounds.
- Use `png/lockup-inverse.png` or `source/lockup-inverse.svg` on dark backgrounds.
- Use the tile icon for favicons, package icons, and social avatars.
- Avoid expanding this into a large marketing system unless you actually need it.
